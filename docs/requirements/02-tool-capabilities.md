# 功能点：工具能力与行为约束

## 总体要求
- 所有工具都以 JSON 请求体接收参数。
- 相对路径默认相对于工作区解析；支持 `~` 展开为用户目录。
- 文本输出需要控制体积，避免一次返回过大内容。
- 目录遍历类工具应尊重 `.gitignore`，并跳过符号链接目录。

## 1. 文件读取 `read`
- 必填参数：`path`。
- 可选参数：`offset`（从 1 开始）、`limit`（最大行数）。
- 支持文本文件读取。
- 支持 `jpg`、`jpeg`、`png`、`gif`、`webp` 图片读取；图片以附件形式返回，并附带 MIME 类型。
- 文本读取默认最多输出 2000 行或 50KB。
- 当内容被截断时，返回继续读取提示，如使用下一个 `offset` 继续。
- 当首行就超过 50KB 时，应提示改用 shell 命令按行读取。
- 路径不存在、路径指向目录、偏移越界都必须报错。

## 2. 命令执行 `bash`
- 必填参数：`command`。
- 可选参数：`timeout`，单位为秒，必须大于 0。
- 在工作区目录下执行命令。
- 默认使用 `SHELL` 环境变量指定的 shell；未配置时回退到 `/bin/sh -lc`。
- 合并返回标准输出与标准错误。
- 默认只保留末尾 2000 行或 50KB；完整输出写入临时文件，并在结果中返回路径。
- 超时、取消或非零退出时，仍返回已有输出，并在尾部补充退出原因。

## 3. 精确编辑 `edit`
- 必填参数：`path`、`edits`。
- `edits` 至少包含一个替换操作，每个操作都必须提供 `oldText` 和 `newText`。
- `oldText` 必须在原文件中精确且唯一匹配。
- 多个替换不得重叠；重叠时必须报错。
- 需要保留 UTF-8 BOM 与原始换行风格。
- 写入完成后返回统一 diff 与首个变更行号。
- 写入过程需要加锁，避免并发覆盖。

## 4. 文件写入 `write`
- 必填参数：`path`、`content`。
- 当父目录不存在时自动创建。
- 允许覆盖已有文件。
- 写入过程需要加锁，避免并发覆盖。

## 5. 内容检索 `grep`
- 必填参数：`pattern`。
- 可选参数：`path`、`glob`、`ignoreCase`、`literal`、`context`、`limit`。
- 默认在工作区根目录搜索；也支持对单个文件搜索。
- 支持正则匹配，也支持字面量匹配。
- 支持大小写不敏感匹配。
- 支持返回命中行前后若干行上下文。
- 遍历目录时必须尊重 `.gitignore`，并跳过二进制文件。
- 默认最多返回 100 个命中；长行最多展示 500 个字符。
- 当命中数、输出字节数或行长度触达限制时，需要在结果中给出提示。

## 6. 文件查找 `find`
- 必填参数：`pattern`。
- 可选参数：`path`、`limit`。
- 仅允许对目录执行查找。
- 遍历目录时必须尊重 `.gitignore`。
- 默认最多返回 1000 个结果。
- 目录结果以 `/` 结尾。
- 当结果数过多或输出超长时，需要在结果中给出提示。

## 7. 目录浏览 `ls`
- 可选参数：`path`、`limit`。
- 仅允许对目录执行浏览。
- 输出包含点文件。
- 结果按名称排序，目录以 `/` 结尾。
- 默认最多返回 500 个条目。
- 空目录返回 `(empty directory)`。

## 8. 通用响应要求
- 成功时返回 `content` 数组。
- 工具附加信息通过 `details` 返回，如截断信息、完整输出路径、diff 等。
- 校验错误与执行错误统一转为结构化响应，供上层调用方消费。
